# الإخلاص للسعادة الزوجية — Al Ikhlas Medical

منصة تجارة إلكترونية وتوعية صحية متخصصة في حلول الصحة الزوجية للرجال والنساء والأجهزة الطبية المنزلية في مصر، مبنية بـ **React 19 + TanStack Router + Tailwind CSS v4 + Vite SSG Prerender + Express / Vercel Functions**.

## المميزات الأساسية

- **هوية بصرية احترافية:** تصميم عربي (RTL) باللون الزمردي الملكي والذهبي الفاخر متوافق مع شعار **الإخلاص للسعادة الزوجية**.
- **متجر متكامل وسريع:** كتالوج منتجات الرجال والنساء والأجهزة الطبية، عروض الباقات، نظام السلة والمفضلة، شحن سري ومجاني للطلبات المؤهلة، ودفع عند الاستلام مع معاينة قبل الاستلام.
- **بنية SEO وتوليد صفحات مسبقة (SSG):** توليد ملفات HTML ثابتة لكل مسار، خرائط الموقع (`sitemap*.xml`)، فيد المنتجات (`catalog-feed.xml` / `.csv` / `.txt`)، وبيانات JSON-LD مهيكلة.
- **بنية محتوى جاهزة للتوسع:** قسم التوعية الصحية (`/education`) وصفحات الأدلة الإرشادية (`/products/guides/$slug`) مهيأة بالكامل لإضافة مقالات وصفحات هبوط جديدة في أي وقت عبر `src/data/articles.ts` و `src/data/landing-pages.ts`.
- **حماية وأمان متقدم:** سياسة CSP صارمة بتوقيع SHA-256، تحقق من الأسعار على الخادم، حماية الخصوصية وعدم تخزين بيانات شخصية في المتصفح.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## البناء والفحص الشامل

```bash
# بناء الإنتاج + توليد الصفحات المسبقة وخرائط الموقع
npm run build

# تشغيل الاختبارات وفحوصات الجودة
npm run lint
npm run typecheck
npm test
npm run test:unit
```

## إعداد متغيرات البيئة والنطاق الجديد

راجع ملف `.env.example` لضبط:

- `SITE_URL`: النطاق الرسمي للموقع (الافتراضي `https://alikhlasmedical.store` — غيّره فور ربط النطاق الجديد، وتبقى جميع مسارات الروابط كما هي تمامًا).
- `GOOGLE_SHEETS_WEBHOOK_URL` و `GOOGLE_SHEETS_WEBHOOK_SECRET`: لربط الطلبات بـ Google Sheets عبر `google-apps-script.gs`.
- تحديث رقم واتساب المتجر الرسمي في `src/lib/whatsapp.ts` (`WHATSAPP_NUMBER`) عند تفعيله.
