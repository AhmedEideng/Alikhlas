# إعداد الشيت + Apps Script: إيه النصوص اللي تحطها وفين بالظبط

مرجع سريع. الملف المرجعي للكود هو `google-apps-script.gs` في جذر المشروع.

الخلاصة: **مفيش أي سر مكتوب جوّه الكود**. الكود بيقرأ كل شيء من **Script Properties**،
وأنت بتكتب نفس القيم **مرة تانية** في **Vercel**. القيمتين لازم تتطابق **حرف بحرف**.

---

## 1) الصق الكود في Apps Script

الطريقة الأسهل (وبتخلي `SPREADSHEET_ID` مش محتاجة أصلاً):

1. افتح الشيت في Google Sheets.
2. **Extensions → Apps Script**.
3. امسح المحتوى الافتراضي، والصق **كل محتوى** `google-apps-script.gs`.
4. **Save** (Ctrl+S) وسمّي المشروع `Al Ikhlas Webhook`.

> لو أنشأت السكريبت من `script.google.com` (standalone) — اسمه وقتها **Standalone** — لازم تحدد `SPREADSHEET_ID` (شرحها تحت).

---

## 2) Script Properties: الأسرار

المكان: **Apps Script → ⚙️ Project Settings → Script properties → Add script property**

| الاسم (بالظبط)       | القيمة                        | إلزامي؟                    | لو ناقص إيه اللي يحصل                                                          |
| -------------------- | ----------------------------- | -------------------------- | ------------------------------------------------------------------------------ |
| `WEBHOOK_SECRET`     | نص عشوائي طويل (64 حرف مثلًا) | 🔴 **إلزامي**              | كل طلب شراء بيترفض (Fail-Closed)، وشيت «الطلبات» ما بيتكتبش فيه حاجة           |
| `REVIEW_READ_TOKEN`  | نص عشوائي تاني **مختلف**      | 🟡 لتفعيل المراجعات        | قراءة المراجعات معطّلة، وقسم المراجعات يختفي من صفحة المنتج (الموقع يعمل عادي) |
| `NOTIFICATION_EMAIL` | إيميلك                        | ⚪ اختياري                 | مفيش إشعار إيميل عند الطلب الجديد                                              |
| `SPREADSHEET_ID`     | **المعرّف بس** مش الرابط      | ⚪ للسكريبت standalone فقط | لو السكريبت من داخل الشيت: **متضيفهاش خالص**                                   |

توليد القيمتين:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

شغّلها **مرتين** — واحدة لـ `WEBHOOK_SECRET` وواحدة لـ `REVIEW_READ_TOKEN`. لازم يكونوا **مختلفين**.

⚠️ **متحطش مسافة في الآخر** وأنت بتلصق. مسافة سرية واحدة = `Forbidden` في كل الطلبات.
⚠️ `SPREADSHEET_ID` = النص اللي بين `/d/` و `/edit` في رابط الشيت، **مش الرابط كامل**.

## 3) التابات والأعمدة: الكود بيعملها بنفسه

مش مطلوب منك تكتب أي رؤوس أعمدة. الكود بينشئ التابين تلقائيًا عند أول تشغيل:

| التاب         | الأعمدة                                                                                                                                                                                                                             |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **الطلبات**   | التاريخ، وقت الطلب، رقم الطلب، حالة الطلب، اسم العميل، الهاتف، المحافظة، العنوان، المنتجات، معرفات المنتجات، المجموع قبل الخصم، قيمة الخصم، خصم الباقة، المجموع بعد الخصم، الشحن، الإجمالي النهائي، ملاحظات، طريقة الطلب، نوع الطلب |
| **المراجعات** | التاريخ، معرف المنتج، اسم المنتج، التقييم، اسم المراجع، الهاتف (للتحقق)، المراجعة، الحالة، شراء موثق                                                                                                                                |

> أسماء التابات بالحرف: `الطلبات` و`المراجعات`. لو غيّرتهم في الشيت لازم تغيّرهم في الكود (`SHEET_NAME` / `REVIEWS_SHEET_NAME`).

**دوال بتشغّلها مرة واحدة من المحرر** (اختر الدالة من القائمة → Run → اسمح بالصلاحيات):

| الدالة                     | بتعمل إيه                                                     | لازم؟               |
| -------------------------- | ------------------------------------------------------------- | ------------------- |
| `hideOrderDiscountColumns` | تخفي عمودَي «قيمة الخصم» و«خصم الباقة» من العرض               | ⚪ اختياري          |
| `migrateOrderSheetColumns` | ترحيل شيت قديم (تضيف «وقت الطلب» وتحذف أعمدة قديمة)           | ⚪ للشيتات القديمة  |
| `setupAutoCleanupTrigger`  | تريجر يومي: حذف بيانات الطلبات بعد 90 يوم والمراجعات المرفوضة | 🟡 موصى به (خصوصية) |

## 4) النشر (Deploy) — الخطوة اللي بتطلع منها الرابط

**Deploy → New deployment → Web app**، وبعدها:

- **Execute as**: `Me (your account)`
- **Who has access**: `Anyone` ← مهم جدًا، وإلا الموقع مش هيقدر يكتب
- **Deploy** → اسمح بالصلاحيات (Authorize access → Advanced → Go to project)

انسخ **Web app URL** — لازم ينتهي بـ **`/exec`** مش `/dev`.

> بعد أي تعديل في الكود: **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**.
> الحفظ بس (Save) مش بينشر التعديل.

---

## 5) Vercel: نفس القيم في الطرف التاني

**Vercel → Project → Settings → Environment Variables → Production** (وPreferable كمان Preview لو بتجرّب):

| المتغير في Vercel              | قيمته                               | يقابل إيه في الشيت  |
| ------------------------------ | ----------------------------------- | ------------------- |
| `GOOGLE_SHEETS_WEBHOOK_URL`    | رابط الـ Web app المنتهي بـ `/exec` | — (مش سر، بس لازم)  |
| `GOOGLE_SHEETS_WEBHOOK_SECRET` | **نفس** قيمة `WEBHOOK_SECRET`       | `WEBHOOK_SECRET`    |
| `GOOGLE_SHEETS_REVIEWS_TOKEN`  | **نفس** قيمة `REVIEW_READ_TOKEN`    | `REVIEW_READ_TOKEN` |

بعد الإضافة: **Redeploy** من Deployments → ⋯ → Redeploy (المتغيرات مش بتتقرأ غير بعد نشر جديد).

## 6) خريطة «فين كل قيمة بتتحط»

| القيمة               |  Apps Script (Script Properties)  |       Vercel (Env Vars)        | `.env` محلي |
| -------------------- | :-------------------------------: | :----------------------------: | :---------: |
| سر كتابة الطلبات     |         `WEBHOOK_SECRET`          | `GOOGLE_SHEETS_WEBHOOK_SECRET` |  نفس الاسم  |
| توكن قراءة المراجعات |        `REVIEW_READ_TOKEN`        | `GOOGLE_SHEETS_REVIEWS_TOKEN`  |  نفس الاسم  |
| رابط الـ Web app     |                 —                 |  `GOOGLE_SHEETS_WEBHOOK_URL`   |  نفس الاسم  |
| إيميل الإشعارات      |       `NOTIFICATION_EMAIL`        |               —                |      —      |
| معرّف الشيت          | `SPREADSHEET_ID` (standalone فقط) |               —                |      —      |

**ملحوظة مهمة:** قيمة `GOOGLE_SHEETS_WEBHOOK_SECRET` و`GOOGLE_SHEETS_REVIEWS_TOKEN` **في Vercel وحدها** — مفيش أي سر بيتحط في GitHub Actions. جيت هب محتاج `GEMINI_API_KEY` بس (لمقالات الأسبوع).

## 7) الاختبار بعد كل ده

1. **الشيت شغال؟**
   افتح الرابط في المتصفح: لو ظهر `{"status":"Al Ikhlas Webhook Active"}` فالنشر تمام.

2. **الكتابة شغالة؟** اعمل أوردر تجريبي من الموقع → الصف يظهر في تاب «الطلبات» في أقل من 10 ثواني.

3. **القراءة شغالة؟**

   ```bash
   curl -s "https://alikhlasmedical.store/api/reviews?product=m-01"
   ```
   - `{"reviews":[]}` = الطرفين متوافقين ومفيش مراجعات معتمدة بعد.
   - `{"reviews":[...]}` = فيه مراجعات معتمدة بتظهر.
   - خطأ 500 = `GOOGLE_SHEETS_WEBHOOK_URL` ناقص في Vercel.

4. **المراجعات بتظهر إزاي؟** العميل يكتب مراجعة → تتسجل بحالة **«قيد المراجعة»** → تفتح الشيت وتغيّر الحالة لـ **«معتمد»** → تظهر على الموقع خلال 5 دقايق (كاش).

## 8) أخطاء شائعة وحلولها

| العرض                                              | السبب                                                         | الحل                                                                     |
| -------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `{"error":"Server configuration error"}` عند الطلب | `GOOGLE_SHEETS_WEBHOOK_URL` أو `..._SECRET` ناقص في Vercel    | ضيفهم + Redeploy                                                         |
| الطلب بيتم لكن مفيش صف في الشيت                    | `WEBHOOK_SECRET` في الشيت مختلف عن Vercel، أو فيه مسافة زيادة | انسخ القيمة من Vercel والصقها في Script Properties، ثم Deploy نسخة جديدة |
| `Forbidden` في المراجعات                           | `REVIEW_READ_TOKEN` ≠ `GOOGLE_SHEETS_REVIEWS_TOKEN`           | نفس الحل: نفس القيمة بالحرف                                              |
| الرابط بيرجع صفحة HTML بتاعة جوجل                  | بتستخدم رابط `/dev` أو النشر مش Web app                       | استخدم رابط `/exec` بعد Deploy جديد                                      |
| `openById` بيفشل                                   | `SPREADSHEET_ID` متسجل كرابط كامل                             | حط المعرّف فقط، أو احذف الخاصية لو السكريبت من داخل الشيت                |
