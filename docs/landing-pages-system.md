# نظام صفحات الهبوط (Landing Page System)

> هذا الملف هو المواصفة المكتوبة، والاختبار
> `src/__tests__/landing-page-depth.test.ts` هو نسختها القابلة للتنفيذ.
> أي صفحة هبوط جديدة تُكتب بهذا القالب أو لا تُنشر.

## 1) الفكرة في سطر

كل صفحة هبوط تجيب على **سؤال شراء واحد** بمحتوى طويل بشري (1300 كلمة+) مبني على
نية بحث واحدة، بلا تكرار لأي جملة أو سؤال في صفحة أخرى، وبلا سعر مكتوب ولا وعد
علاجي — ثم تنتهي بروابط داخلية لمنتجات ومقالات ومصادر موثوقة.

## 2) مكان المحتوى

- الملف: `src/data/landing-pages.ts` — المصفوفة `seoLandingPages`.
- المسار: `/products/guides/:slug` (`src/routes/products.guides.$slug.tsx`).
- ثلاث نسخ عرض يجب أن تبقى متطابقة في النص والترتيب:
  1. واجهة React (الصفحة نفسها).
  2. HTML ثابت للزاحف (`scripts/prerender-seo.mjs` → `dist/products/guides/*.html`).
  3. ملف JSON لكل صفحة (`scripts/generate-sitemap.mjs` → `public/landing-pages/*.json`).
- أي حقل جديد في `SeoLandingPage` يُضاف في **الثلاثة**، وإلا تظهر الصفحة ناقصة في
  النسخة الثابتة بينما تعمل في المتصفح.

## 3) قالب الصفحة (الترتيب إلزامي)

| الحقل | الوظيفة | الحد الأدنى |
|---|---|---|
| `slug` | رابط ثابت `[a-z0-9-]` | — |
| `title` | H1 بسؤال/مقارنة يفهمه العميل | 8 أحرف |
| `metaTitle` | عنوان SERP | ≤ 62 حرفًا (`fitSerpTitle`) |
| `metaDescription` | وصف SERP | ≤ 155 حرفًا بعد التطبيع |
| `eyebrow` | تصنيف أعلى الصفحة | «دليل شراء» |
| `heroDescription` | سطر واحد يحمل الكلمة المفتاحية | يحتوي الكلمة أو كلمة مرتبطة |
| `intro` | تمهيد 90–150 كلمة يفتح السؤال ويحدد ما ستحصل عليه | — |
| `keyTakeaways` | 4–5 نقاط تُقرأ سريعًا | كل نقطة ≥ 8 كلمات |
| `sections` | 7 أقسام أو أكثر (التفصيل أدناه) | 7 |
| `comparison` | جدول مقارنة عملي | 3 أعمدة+ / 3 صفوف+ |
| `productIds` | منتجات حقيقية من الكتالوج | كل معرّف موجود |
| `links` | روابط داخلية (مقالات/أقسام) | 2 على الأقل |
| `faqs` | 6–8 أسئلة، إجابات 30–95 كلمة | 6 |
| `primaryKeyword` | كلمة أساسية واحدة | مختلفة في كل صفحة |
| `relatedKeywords` | 4 كلمات مرتبطة | 3 تظهر في المتن |
| `sources` | مصادر موثوقة (WHO/NHS/Mayo/Cleveland/FDA…) | 2 على الأقل |
| `updatedAt` | تاريخ تحديث ظاهر | `YYYY-MM-DD` |

### القسم الواحد

```ts
{
  heading: "…",          // سؤال أو حكم واضح، لا كلمة واحدة
  body: "…",             // يجيب على العنوان فورًا (28 كلمة+)
  paragraphs: ["…", "…"],// فقرتان توسّع (30 كلمة+ لكل فقرة)
  bullets: ["…"],        // 3 نقاط عملية على الأقل
}
```

- مجموع كلمات القسم ≥ 140 كلمة.
- مجموع كلمات المتن (بدون الميتا) ≥ 1300 كلمة.
- ترتيب الأقسام المعتمد: الفرق/الإجابة → كل خيار على حدة → كيف تقرأ الصفحة أو
  تختار → الأخطاء الشائعة → التحذيرات → متى تراجع مختصًا.

## 4) قواعد الكتابة (بشرية لا آلية)

1. **إجابة أولًا**: أول جملة في `intro` وأول جملة في كل قسم تجيب قبل أي خلفية.
2. **جمل متوسطة**: متوسط طول الجملة ≤ 32 كلمة، وأطول جملة ≤ 48 كلمة. لا فقرة
   تتجاوز 150 كلمة.
3. **نبرة مصرية مهنية**: فصحى مبسّطة مع لمسة عامية في الشروح («إيدك»، «مش»)،
   بلا مبالغة تسويقية.
4. **الكلمة المفتاحية**: تظهر 4 مرات على الأقل في المتن طبيعيًا (لا حشو)، وتظهر
   في `heroDescription` أو العنوان، مع 3 كلمات مرتبطة على الأقل في المتن.
5. **كل معلومة من صفحة المنتج أو من مصدر مذكور**: لا أرقام مخترعة، ولا نسب
   مستنتجة، ولا بلد منشأ، ولا ادعاء طبي.
6. **صفر أسعار**: ممنوع أي مبلغ أو لفظ عملة داخل النص. السعر يظهر تلقائيًا في
   بطاقتي المنتج من الكتالوج.
7. **صفر وعود**: ممنوع «يعالج/يشفي/مضمون/بدون أعراض/100%/أفضل منتج/أقوى منتج»
   إلا داخل جملة نفي صريحة.
8. **الأمان حاضر دائمًا**: كل صفحة تذكر «مختص»، وإشارة توقف («يُوقف/توقف»)،
   وأعراضًا تستدعي التوقف (ألم/احمرار/تهيج/حساسية).
9. **تفرّد صارم**: لا تشارك أي جملة من 9 كلمات متتالية مع صفحة أخرى، ولا سؤالًا،
   ولا إجابة، ولا عنوان قسم. كل صفحة تُكتب من الصفر ولو تشابهت الموضوعات.

## 6) خطوات إضافة صفحة هبوط جديدة

1. اختر **نية بحث واحدة** من استعلامات الشراء الحقيقية (مثال: «أيهما أختار»، «كيف
   أقرأ العبوة»، «يدوي أم كهربائي»). لا تكرر نية صفحة موجودة.
2. حدّد الكلمة الأساسية و4 كلمات مرتبطة، وتأكد من عدم استخدامها في صفحة أخرى.
3. اجمع الحقائق: من صفحات المنتجات الموجودة (usage/ingredients/warnings) ومن
   مصدرين موثوقين. لا تكتب رقمًا لا تجده.
4. اكتب الأقسام بالترتيب المعتمد: 7–9 أقسام، كل قسم `body` + فقرتان + 3 نقاط.
5. اكتب 4–5 نقاط «أهم النقاط»، وجدول مقارنة بثلاثة أعمدة أو أكثر، و6–8 أسئلة
   (إجاباتها 30–95 كلمة وتفتح موضوعًا لا تغلقه).
6. اربط الصفحة: `productIds` من الكتالوج، `links` لمقالة أو قسمين، ثم أضف الـ
   `slug` إلى `guideSlugs` في عنقود الموضوعات المناسب داخل `src/data/topics.ts`.
7. شغّل: `npx vitest run` ← ثم `npm run build` (يولّد JSON + sitemap) ← ثم
   `npm run ci`. لا تُعدّل الاختبار لتُمرّر نصًا أضعف؛ عدّل النص.

## 7) أخطاء ممنوعة (تُفشل البوابات مباشرة)

- كتابة مبلغ أو «جنيه/ج.م» داخل نص الدليل.
- قسم بفقرة واحدة فقط، أو قسم بلا نقاط عملية.
- نسخ فقرة أو سؤال من صفحة أخرى «مع تعديل كلمة».
- وعد بزمن نتيجة («خلال دقائق ستلاحظ…») أو «نتيجة مضمونة».
- تجاوز «متى تراجع مختصًا» أو حذف التحذيرات لتقصير الصفحة.
- إضافة صفحة بلا مصدر، أو بمصدر واحد، أو بتاريخ تحديث قديم لا يُحدَّث.
- ربط الصفحة بمنتجات غير موجودة أو بمنتجات لا علاقة لها بالموضوع.
